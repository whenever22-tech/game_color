# 컬러팝 · COLOR POP

30초로 시작해 혼자 색이 다른 타일을 찾는 한국어 브라우저 게임입니다. 정답은 1점입니다.

- 연속 정답 5회에 3초를 추가합니다.
- 6회 연속부터는 정답마다 1초를 추가합니다(10회, 15회도 1초).
- 콤보 알림은 5, 10, 15회 등 5의 배수에서만 잠깐 표시됩니다.
- 오답은 연속 기록을 0으로 초기화합니다. 점수와 남은 시간은 차감하지 않습니다.
- 다시 시작하면 점수와 연속 기록은 0, 시간은 30초가 됩니다.
- 타일은 2점마다 증가합니다: 0~1점 2×2, 2~3점 3×3, 4~5점 4×4, 6~7점 5×5, 8점 이상 6×6.
- 색 명도 차이는 처음 18%p에서 정답마다 12%씩 줄어들며 최솟값은 3%p입니다. 기존보다 타일이 두 배 빠르게 늘고 색 차이가 빠르게 줄어듭니다.

## 가장 간단한 실행

ZIP 파일을 압축 해제한 뒤 폴더 안의 `index.html`을 더블클릭하세요. Node.js 설치 없이 실행됩니다. 파일을 직접 열면 브라우저에 따라 최고 기록 저장이 제한될 수 있습니다.

## 서버로 실행

Node.js 22 이상에서 저장소 디렉터리로 이동해 실행합니다.

```sh
npm start
```

기본 포트는 3000이며 `PORT` 환경 변수로 변경할 수 있습니다. 서버는 `0.0.0.0`에서 수신합니다. 게임 실행에는 패키지 설치, 외부 서비스, 로그인, API 키가 필요 없습니다. `index.html`, `style.css`, `game.js`를 정적 호스팅에 함께 올릴 수도 있습니다.

최고 기록은 이 사이트의 브라우저 localStorage에 저장됩니다. 브라우저 데이터를 삭제하면 기록도 사라집니다. 저장이 차단된 경우 현재 페이지 안에서만 기록을 유지하며 게임은 계속 동작합니다.

## 테스트

```sh
npm ci --cache /tmp/game-color-npm-cache
npm test
```

Playwright와 Chromium을 사용합니다. 클라우드 환경의 `/usr/bin/chromium`이 기본 실행 경로이며, 다른 환경은 `CHROMIUM_PATH`로 Chromium 실행 파일을 지정합니다.

테스트는 정답·오답 처리, 콤보 표시와 시간 보너스, 연속 기록 초기화, 난이도 상승, 30초 종료, 기록 저장과 새로고침, 재시작, 모바일 터치, 화면 넘침, 저장 차단 시 동작, 외부 요청 부재를 검증합니다. 시간 종료는 브라우저 가상 시계로 검증합니다.
